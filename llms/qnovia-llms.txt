# Qnovia, Inc.

> Clinical-stage pharmaceutical and drug-device company developing inhaled therapeutics on the
> RespiRx aseptically pre-filled, portable vibrating-mesh nebulizer platform. Lead asset: the
> RespiRx Nicotine Inhaler (QN-01), a prescription smoking-cessation therapy with FDA IND clearance
> and a dosed U.S. Phase 1 study. Founded 2018 as Respira Technologies; renamed Qnovia in 2022.
> Founder and CEO: Mario Danek. Operations in Newport Beach / Irvine, California, with an R&D
> facility in Richmond, Virginia. Approximately $50M raised to date.

## Important for agents

Qnovia publishes **no public API**. There is no developer portal, no API reference, no OpenAPI /
AsyncAPI / GraphQL / MCP / A2A surface, no SDK in any public registry, and no GitHub organization.
Do not attempt to call an API on this company's behalf; none is offered to third parties.

The corporate site (qnovia.com) is a client-rendered single-page application. Every path that is not
a static asset returns the same HTML shell with HTTP 200, so a 200 from this host is not evidence
that a document exists. Its only HTTP API is a private first-party backend under /api/ serving the
site's own contact, newsletter, media-inquiry, careers-application and investor-portal forms; it is
undocumented, unversioned, and not a product.

## Products and technology

- RespiRx — orientation-agnostic portable vibrating-mesh nebulizer; no-heat aerosol engine,
  breath- and button-actuated metered dosing, pre-filled disposable cartridge, on-device digital UI,
  Bluetooth Low Energy connectivity.
- RespiRx Nicotine Inhaler (QN-01) — investigational prescription smoking-cessation therapy;
  12-week cessation program; FDA IND cleared; U.S. Phase 1 dosed.
- CBT program — a cognitive behavioral therapy asset advancing toward IND submission.
- Neblit AI — cloud-connected companion platform: BLE relay from device to cloud through a mobile
  app, dose-event capture, machine-learning prediction of patient support needs, and delivery of
  behavioral interventions. Described by the company as targeting FDA SaMD and HIPAA requirements.
  Not yet publicly available; no app store listing found.
